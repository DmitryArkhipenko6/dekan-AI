# Dekan-AI: Онлайн деканат
## Стек
Выполнено в трех контейнерах:
- серверная часть — Python 3.12, FastAPI, собственно PyTecceract;
- фронт — NGINX, NodeJS, React с оформлением под Material;
- LLM — Ollama с qwen2.5:3b
